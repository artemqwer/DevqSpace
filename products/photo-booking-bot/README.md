# 📸 PhotoBooking Bot — Telegram-бот для фотографів і фотостудій

Повнофункціональний готовий Telegram-бот для комерційних фотографів, контент-мейкерів та фотостудій з **вбудованою інтерактивною адмін-панеллю прямо в Telegram** та **веб-інтерфейсом**.

> 💡 **Головна особливість**: Будь-яка людина без жодних знань програмування та без необхідності редагувати вихідний код чи `.env` може повністю змінити ціни, послуги, контакти, портфоліо, реквізити та розклад прямо через кнопки в Telegram!

## 🌟 Можливості бота

### Для клієнтів:
* 📅 **Онлайн-запис на зйомку за 1 хвилину**: вибір послуги, дати на 14 днів уперед, доступного часу в календарі, вказівка побажань.
* 💰 **Презентація пакетів та цін**: опис, тривалість, розмір завдатку, що входить у вартість.
* 🖼 **Портфоліо за стилями**: інтерактивний перегляд знімків за категоріями (Портрет, Love Story, Весілля, Студія, Контент).
* 💳 **Прийом завдатку**: зручна оплата в 1 клік через банку Monobank або за номером картки з можливістю прикріпити чек/скріншот.
* 📍 **Локації**: список рекомендованих студій, парків та локацій для зйомок.
* 📄 **Гайд підготовки**: автоматична пам'ятка для клієнта (поради щодо образу, одягу, макіяжу та таймінгу).
* ⏰ **Автоматичні нагадування**: бот сам нагадує про зустріч за 24 години та за 2 години до зйомки.

### Для фотографа / адміністратора (вбудована адмінка):
* 👑 **Команда `/admin`**: доступ до панелі за PIN-кодом (за замовчуванням `7788`).
* 📸 **Керування послугами (CRUD)**:
  * Додавання нових пакетів фотосесій.
  * Редагування назви, опису, вартості, завдатку та тривалості.
  * Тимчасове приховування (увімкнути/вимкнути) або видалення.
* 🖼 **Керування портфоліо**:
  * Завантаження фото прямо в чат з ботом у відповідну категорію.
  * Видалення застарілих фотографій.
* 📋 **Керування бронюваннями**:
  * Миттєве сповіщення про нову заявку або чек.
  * Підтвердження, відхилення або завершення зйомки.
  * Фіксація отриманого завдатку в 1 кнопку.
* 💳 **Реквізити та налаштування оплати**:
  * Зміна номера картки та посилання на Monobank банку.
  * Увімкнення / вимкнення обов'язкового завдатку.
  * Зміна стандартної суми завдатку.
* 🚫 **Графік та блокування вихідних**:
  * Можливість заблокувати будь-яку дату (відпустка/вихідний), щоб клієнти не могли її обрати.
* 📝 **Редагування гайду підготовки**:
  * Зміна тексту пам'ятки клієнта в один клік.
* ⏰ **Налаштування нагадувань**:
  * Увімкнення/вимкнення та зміна тексту нагадувань за 24г та 2г.
* 📢 **Масова розсилка**:
  * Відправка анонсів, сезонних знижок або акцій усім клієнтам у базі.
* 👥 **Керування командою**:
  * Додавання асистентів/адміністраторів, зміна PIN-коду.
* 🌐 **Веб-панель**: доступний також веб-інтерфейс за адресою `http://IP_СЕРВЕРА:8080`.

## 🚀 Швидкий запуск

### Варіант 1. Запуск через Docker (найпростіший)
1. Створіть файл `.env` та вкажіть ваш токен бота:
```bash
cp .env.example .env
nano .env # вкажіть BOT_TOKEN=...
```
2. Запустіть контейнер:
```bash
docker compose up -d --build
```

### Варіант 2. Запуск через Python (Linux / macOS / Windows)
Вимоги: Python 3.10+
1. Клонуйте або розпакуйте архів з ботом:
```bash
cd photo-booking-bot
```
2. Створіть `.env` з вашим токеном від `@BotFather`:
```bash
cp .env.example .env
```
3. Запустіть скрипт:
```bash
./run.sh
```
Або вручну:
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python bot.py
```

## 🔑 Перший вхід в адмінку
1. Напишіть боту в Telegram команду `/start`.
2. Напишіть команду `/admin`.
3. Введіть PIN-код: **`7788`** (його можна змінити в розділі «Керування адмінами»).
4. Готово! Тепер ви адміністратор бота і маєте повний контроль над усіма параметрами.

## 📁 Структура проєкту
```
photo-booking-bot/
├── bot.py                  # Головний запуск бота, планувальника та веб-сервера
├── config.py               # Конфігурація та змінні середовища
├── requirements.txt        # Python бібліотеки
├── Dockerfile              # Докер-образ
├── docker-compose.yml      # Конфіг для запуску в 1 команду
├── run.sh                  # Зручний баш-скрипт запуску
├── database/
│   ├── db.py               # Асинхронне підключення SQLite та початкові дані
│   └── models.py           # Запити до бази даних
├── handlers/
│   ├── client.py           # Сценарії клієнта: меню, портфоліо, запис, чеки
│   └── admin.py            # Повна адмін-панель: налаштування, ціни, розклад, розсилка
├── keyboards/
│   ├── client_kb.py        # Кнопки для клієнтів та календар
│   └── admin_kb.py         # Кнопки панелі керування
├── services/
│   ├── calendar_service.py # Розрахунок вільних слотів та графіка
│   └── reminder_service.py # Автоматичні нагадування клієнтам
├── web/
│   ├── app.py              # Веб-панель керування на aiohttp
│   └── templates/
│       └── dashboard.html  # Темний сучасний веб-дашборд
└── data/                   # Локальна база booking.db та завантажені файли
```

## 🛡 Безпека та надійність
* Уся інформація зберігається у швидкій локальній базі **SQLite** (`data/booking.db`).
* Жодних зовнішніх платно-залежних баз даних — дані завжди під вашим контролем.
* Автоматичні нагадування працюють у фоні навіть при перезавантаженні.
